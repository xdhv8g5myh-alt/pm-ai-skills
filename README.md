# pm-ai-skills

PM AI 协作平台的 Claude Code 技能包，覆盖需求分析 → 原型 → PRD → 前端交付全流程。

## 目录

| 路径 | 说明 |
|------|------|
| `.pai/skill-update/` | 技能定义（pm-analyze / pm-prototype / pm-prd / pm-deliver / pm-autopilot / pm-common / generate-mini-app） |
| `.claude/commands/` | 斜杠命令（`/pm-analyze`、`/pm-autopilot` 等） |

## 使用

将本仓库内容放到 Claude Code 工作区后，用触发词或斜杠命令：

- `/pm-autopilot` — 全流程自动编排（一键跑完 4 步）
- `/pm-analyze` — 需求分析
- `/pm-prototype` — 原型生成
- `/pm-prd` — PRD 文档
- `/pm-deliver` — 前端交付
