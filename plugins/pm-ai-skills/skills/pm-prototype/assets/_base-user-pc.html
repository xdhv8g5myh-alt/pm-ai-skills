基础布局模板使用说明
此文件提供完整的 pc-header + pc-main + pc-footer + proto-toolbar 标准布局骨架。 复制本文件，修改 pageTitle / activePage 的值，并在 pc-main 内替换为页面内容即可。
脚本加载顺序
1. vue.global.prod.js 2. arco-vue.min.js 3. proto-utils.js
CSS 引用
1. arco.css 2. theme.css 3. <style> 内联样式
Mount 方式
createApp({setup(){...}}) .use(ArcoVue) .mount('#app')
注意事项
v-cloak 在 #app 上 自定义标签完整闭合 组件用 <a-*> 前缀
JS 基础模板
const { createApp, ref, reactive } = Vue createApp({ setup() { const pageTitle = ref('页面名称') const activePage = ref('home') // home/list/detail/checkout/profile const pageState = ref('normal') // normal/loading/empty/error // mock data ... return { pageTitle, activePage, pageState } } }).use(ArcoVue).mount('#app')
