# 用户前台 PC 原型规格

## 布局结构
```
固定顶部导航（64px）
├── Logo（左）
├── 主导航链接（中）
└── 搜索+通知+头像（右）

主内容区（padding-top: 64px）

页脚
```

## 常用页面类型

### 首页（home）
- Hero 区（全宽渐变背景）
- 特性/功能介绍（4列卡片网格）
- 内容列表

### 列表/发现页（list）
- 左侧分类侧栏（240px）
- 右侧内容列表
- 顶部搜索筛选

### 详情页（detail）
- 两列布局：左侧内容+评论，右侧信息栏

### 个人中心（profile）
- 顶部用户信息横幅
- Tabs 切换（项目/收藏/动态）

### 结算页（checkout）
- 步骤条
- 表单区 + 右侧摘要

## 内联样式类（各页面自行定义）
各页面在 `<style>` 中定义 `.pc-header` `.pc-nav` `.pc-hero` `.pc-section` `.pc-card` 等类。
